MCP-kobling til dataene

Alt nettstedet viser, kan du spørre om selv. En MCP-server (Model Context Protocol) gir Claude, Codex, Kimi, GLM og egne script de samme tallene som verktøy: tidsseriene bak indeksen, hvert yrke med oppgaver og Claude-bruk, og hver utdanning. Alt er aggregerte tall som allerede er offentlige. Ingen innlogging. Feil og ideer: bruk knappen «Tilbakemelding» nederst til høyre, eller verktøyet send_feedback.

Koble til

Endepunktet er https://kiindeksen-mcp.fly.dev/mcp (Streamable HTTP, JSON-RPC 2.0).

Claude Code. Én kommando:

claude mcp add --transport http kiindeksen https://kiindeksen-mcp.fly.dev/mcp

claude.ai. Settings, Connectors, Add custom connector. Lim inn adressen over. Deretter kan du be Claude om for eksempel «hent hovedtallet med usikkerhet for de under 31 år» eller «sammenlign yrkene 4110 og 3312».

Eget script. client_example.py viser hele samtalen med serveren og trenger bare Python, ingen pakker:

python3 client_example.py

Andre klienter og modeller

Koblingen er åpen MCP over HTTP og er ikke knyttet til Claude. Alle klienter som tar en adresse, kan bruke den, og adressen er den samme overalt: https://kiindeksen-mcp.fly.dev/mcp.

KlientSlik legger du til
Codex CLI (OpenAI)codex mcp add kiindeksen --url https://kiindeksen-mcp.fly.dev/mcp, eller i ~/.codex/config.toml: [mcp_servers.kiindeksen] med url = "https://kiindeksen-mcp.fly.dev/mcp"
Kimi Code CLI (Moonshot)kimi mcp add --transport http kiindeksen https://kiindeksen-mcp.fly.dev/mcp
GLM fra Z.aiModellene brukes gjennom Claude Code, OpenCode, Cline eller Kilo Code. Legg koblingen til i den klienten du bruker; kommandoen for Claude Code står over.
OpenCodeI opencode.json: "mcp": {"kiindeksen": {"type": "remote", "url": "https://kiindeksen-mcp.fly.dev/mcp", "enabled": true}}
Gemini CLII ~/.gemini/settings.json: "mcpServers": {"kiindeksen": {"httpUrl": "https://kiindeksen-mcp.fly.dev/mcp"}}
Cursor, VS Code, Cline og andreLegg til en server av typen HTTP (Streamable HTTP) med adressen over. Klienter som bare kjenner den eldre SSE-transporten, bruker https://kiindeksen-mcp.fly.dev/sse.
Klienter som bare starter lokale servereLast ned server.py og registrer kommandoen python3 server.py --stdio. Den henter dataene fra nettstedet og trenger ingen pakker.

Fra kode, hos hvilken som helst leverandør

Modell-API-ene til OpenAI og Anthropic kaller serveren direkte, uten egen MCP-klient. Hos OpenAI (Responses API) er verktøyet {"type": "mcp", "server_label": "kiindeksen", "server_url": "https://kiindeksen-mcp.fly.dev/mcp", "require_approval": "never"}. Hos Anthropic (Messages API, beta-hode mcp-client-2025-11-20) står serveren som {"type": "url", "url": "https://kiindeksen-mcp.fly.dev/mcp", "name": "kiindeksen"} i mcp_servers, og verktøyet er {"type": "mcp_toolset", "mcp_server_name": "kiindeksen"}.

Alle andre modeller med funksjonskall, som Kimi, GLM, Gemini eller Mistral, kan bruke de samme verktøyene som vanlige HTTP-kall. Hvert verktøy finnes som GET /tools/<navn> med argumentene i spørrestrengen (lister kommaseparert) eller som POST med JSON-kropp. openapi.json beskriver dem, så GPT-er, Dify, Coze og lignende plattformer kan importere dem. Prøv:

curl "https://kiindeksen-mcp.fly.dev/tools/get_headline?young=true&reference=claudecode"
curl "https://kiindeksen-mcp.fly.dev/tools/compare_occupations?codes=4110,3312&index_base=2025-02"

To ressurser (kiindeksen://om, kiindeksen://konvensjoner) og to prompter (analyser_yrkespar, maanedsrapport) følger med.

Konvensjoner

  • Tidsseriene er indekser med 100 i november 2022, måneden ChatGPT kom. Bruk index_base for å flytte basen, for eksempel 2025-02 for Claude Code.
  • sa er sesongjustert, percap er per innbygger i aldersgruppen.
  • KI-indeksen er veksten i den mest eksponerte femdelen mot veksten i den minst eksponerte, i prosentpoeng. get_headline gir nettstedets tall med usikkerhet. get_growth lar deg regne på egne referanser og glattinger.
  • Yrker er STYRK-08 på fire siffer. Bare yrker med minst 30 lønnstakere hver måned har tidsserie. Automatisering er Anthropics regel: direkte delegering pluss tilbakemeldingssløyfe.
  • Utdanninger er NUS-faggrupper på tre siffer, nivå pluss fag.
  • Oppgi release, spesifikasjon og basismåned når du rapporterer tall.

Eksempel: samme eksponering, ulik automatisering

Spørsmålet: to yrker har nesten samme KI-eksponering. Brukes KI likt i dem, og går det likt med sysselsettingen? Dette er det client_example.py gjør, og det Claude gjør hvis du ber om prompten analyser_yrkespar med kodene 4110 og 3312.

  1. get_release og get_headline. Release 2026-10 dekker januar 2021 til juli 2026. KI-indeksen for 21–60 år med ChatGPT som referanse er +1,5 prosentpoeng, standardfeil 2,7. For 21–30 år siden Claude Code er den −2,9, standardfeil 2,0.
  2. get_growth på by_exposure med referanse 2025-01 og tre måneders glatting. Fra januar 2025 til juli 2026, sesongjustert: minst eksponerte femdel −0,3 prosent, mest eksponerte −0,3 prosent. Gapet er −0,1 prosentpoeng. Samme kall på age_by_exposure for 21–30 år: −1,8 i minst eksponerte, −4,6 i mest eksponerte.
  3. compare_occupations med kodene 4110 og 3312, sysselsetting, sesongjustert, basismåned 2025-02:
    YrkeEloundouMouchelAutomatisering (feb. 2026)Sysselsetting juli 2026
    4110 Kontormedarbeidere0,59 (Q5)0,59 (Q5)67 %95,7
    3312 Kundebehandlere lån og kreditt0,61 (Q5)0,62 (Q5)30 %96,5
  4. get_occupation for hvert yrke, plattform claude_ai, gir oppgavene. Kontormedarbeidere: feilsøking av kontorutstyr (1,26 prosent av all Claude-bruk, automatisering 60 prosent), skjemaer og reiseregninger (66 prosent) og kontormaskiner (51 prosent). Kundebehandlere: anbefale økonomisk strategi (24 prosent), forklare kredittvurdering og regelverk (22 prosent) og forklare lånetyper (27 prosent).
  5. Tolkningen skriver du selv: samme eksponeringsskår, men i det ene yrket bestilles arbeidet ferdig, i det andre drøftes det. Det er det eksponeringsmålet ikke ser og bruksdataene viser.

Samme øvelse for en utdanning: search_education med «økonomi» på bachelornivå gir faggruppe 641 Økonomisk-administrative fag. Den har 101 315 sysselsatte, eksponering 0,55, halvparten i den mest eksponerte femdelen og automatisering 43 prosent. get_education_group gir de ti vanligste oppgavene i jobbene og de vanligste jobbene, regnskapsførere øverst.

Alle tall over er lest fra serveren 15. oktober 2026 med release 2026-10. Nye releaser gir nye tall. Kjør scriptet på nytt.

Drift og kildekode

Serveren henter JSON-filene fra kiindeksen.no ved oppstart og hver sjette time, så den følger den månedlige releasen uten ny utrulling. Den er skrevet i Pythons standardbibliotek og kjører som egen Fly.io-app i Stockholm. Kildekoden ligger i dashboard/mcp/ i prosjektets repo, og server.py kan lastes ned herfra. Du kan kjøre den lokalt mot nedlastede datafiler med python3 server.py --data-dir <mappe> --port 8765.
